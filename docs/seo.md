## Open Graph Rules

- OG title should match page title but can be more conversion-focused.
- OG description should state problem, solution, and audience.
- Each locale route must define its own Open Graph title and description.
- `/en` uses `en_US`; `/zh` uses `zh_CN`.
- Add alternate language metadata between `/en` and `/zh`.
- OG image should use branded orange/blue treatment and clear Chinese-first headline.
- Use one OG image template per page type: marketing page, article, case study.
- Keep OG images under `/public/assets/website/og`.

## Structured Data Ideas

- `Organization` for AGA Ventures.
- `LocalBusiness` for Malaysia presence.
- `Service` for AI automation, Lark systems, and SME digital transformation.
- `FAQPage` for common SME systemization questions.
- `Article` for insights and SEO articles.
- `BreadcrumbList` for all nested pages.

## Internal Linking Rules

- Home links to Services, Solutions, Case Studies, Insights, Contact.
- Services pages link to relevant Solutions and Contact.
- Solutions pages link to related Case Studies and Services.
- Case Studies link back to the service and industry solution used.
- Insights link to Services, Solutions, and relevant CTA.
- Footer contains links to all primary pages.
- Every SEO article should include at least two internal links and one conversion CTA.
